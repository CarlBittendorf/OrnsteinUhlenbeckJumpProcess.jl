The Ornstein–Uhlenbeck model ​

A hierarchical Ornstein-Uhlenbeck model for longitudinal observations, exported as OrnsteinUhlenbeckModel. The model estimates group-level and subject-level equilibrium means, mean-reversion rates, and stationary standard deviations. The data conventions are shared with all other models; see Models.

julia
using OrnsteinUhlenbeckJumpProcess

model = OrnsteinUhlenbeckModel(;
    group_indices = [1, 1],
    subject_indices = [1, 1, 2, 2],
    z_obs = [0.5, 0.6, 0.7, 0.4],
    Δt = [0.0, 1.0, 0.0, 2.0],
    is_transition = [false, true, false, true]
);

Implementation notes ​

The implementation is non-centered: the transition noise enters through a standardized z_raw vector and the subject-level parameters are reconstructed from standardized effects, which improves the geometry of the posterior for gradient-based samplers.
