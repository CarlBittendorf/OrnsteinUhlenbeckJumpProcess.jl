Jump model workflow ​

This page fits OrnsteinUhlenbeckJumpModel to synthetic data with measured events and analyzes the event-reactivity parameters. The workflow is identical to Analysis workflow; here we focus on the event-related parts.

Simulating event-related jumps ​

Each node carries the magnitude of the positive or negative event associated with it, scaled to , and the time between the preceding node and the event. We draw observations from a data-generating model with the default priors:

julia
using OrnsteinUhlenbeckJumpProcess, StableRNGs, Turing
using OrnsteinUhlenbeckJumpProcess.AlgebraOfGraphics: set_aog_theme!

set_aog_theme!()

data = (;
    group_indices = [1, 2],
    subject_indices = [1, 1, 1, 2, 2, 2],
    Δt = repeat([0.0, 8.0, 16.0], 2),
    M⁺ = [0.0, 0.01, 0.0, 0.0, 0.0, 0.005],
    M⁻ = [0.0, 0.0, 0.002, 0.0, 0.0, 0.0],
    Δτ = [0.0, 4.0, 2.0, 0.0, 0.0, 6.0],
    is_transition = repeat([false, true, true], 2)
)
generative = OrnsteinUhlenbeckJumpModel(; data..., z_obs = missing)
z_obs = rand(StableRNG(1), generative).z_obs;

model = OrnsteinUhlenbeckJumpModel(; data..., z_obs = z_obs);
DynamicPPL.Model{typeof(OrnsteinUhlenbeckJumpModel), (), (:group_indices, :subject_indices, :z_obs, :Δt, :M⁺, :M⁻, :Δτ, :is_transition), (), Tuple{}, Tuple{Vector{Int64}, Vector{Int64}, Vector{Float64}, Vector{Float64}, Vector{Float64}, Vector{Float64}, Vector{Float64}, Vector{Bool}}, DynamicPPL.DefaultContext}(OrnsteinUhlenbeckJumpProcess.OrnsteinUhlenbeckJumpModel, NamedTuple(), (group_indices = [1, 2], subject_indices = [1, 1, 1, 2, 2, 2], z_obs = [0.34783935803271643, 0.5527366356984493, 0.41129208931003347, 0.7003013219194446, 0.6759228886494179, 0.8866891943976226], Δt = [0.0, 8.0, 16.0, 0.0, 8.0, 16.0], M⁺ = [0.0, 0.01, 0.0, 0.0, 0.0, 0.005], M⁻ = [0.0, 0.0, 0.002, 0.0, 0.0, 0.0], Δτ = [0.0, 4.0, 2.0, 0.0, 0.0, 6.0], is_transition = Bool[0, 1, 1, 0, 1, 1]), DynamicPPL.DefaultContext())

Zeros in M⁺ and M⁻ mark nodes without an event of that kind, so their magnitudes do not influence the likelihood.

Fitting the model ​

julia
chains = sample(StableRNG(1), model, NUTS(), 200; progress = false);
size(chains)
(200, 51, 1)

julia
